## Overview
Manoa Club Compass is a centralized directory for UH Manoa student organizations. It helps students discover clubs, browse by interest area, and find meeting and contact information. At a club fair you would have to walk around and go through every single club to find a couple that you are interested in, we fixed this problem by creating a tool that lets you sort by your interests and locate clubs that you have a higher chance of joining. This app is intended to help students find clubs that they are interested in and get in contact with them after finding a good club.

## Contributions
Me and my group members split up so we would each work on every part of the project. Each person worked on adding to the project homepage, developing Club Compass, and planning the milestones and tasks to do. For the project homepage I focused on the developer guide and updating screenshots to where our project is currently at. This wasn't very difficult as this was similar to what I've done previously with my professional portfolio and I also had references to what the homepage should look like based on the instructions. For developing the Club Compass I added features that allowed users to look up clubs based on their interests and added testing to make sure that every page was accessible and functioning. For planning the project I created the Milestone 3 project issue board and planned out the next steps to complete the requirements. 

## What I learned
Creating this project I learned how to use github to work as a team rather than saving previous commits to the project. I found it useful to be able to see what other people changed by looking at what they committed rather than reading the code to see what was updated. In this class, this project was the first time I had to deal with testing the pages so I had to learn how to implement the playwright testing for every single page that the user may see.
