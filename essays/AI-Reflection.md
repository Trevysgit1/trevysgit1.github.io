## Introduction
I think that AI is a very useful tool for Software Engineering, it allows you to write new code, debug, consult, and more. In education, AI can help students better understand difficult concepts by using AI as a study tool to provide explanations, examples, and feedback. AI in education also relates to software engineering because AI can assist with many different areas and can solve many different problems that programmers commonly face. I have used AI in software engineering to solve problems like code generation, debugging, and different ways to solve a problem. The AI tool that I have mainly used is Github Copilot that is implemented in VSCode, sometimes Copilot would autofill what I was going to type or even write the function based off the function name.

## Personal Experience with AI
1. Experience Quizzes, For the experience quizzes I did not use AI because I felt like I should learn the topics fully before I can use a tool that does the work for me. The assignments where there were videos were also helpful because I could watch them if I got stuck following the instructions or did not know what to do
2. Practice Quizzes, For these experiences I did use Github Copilot to generate some functions or help with debugging problems that I didn't see before or know how to resolve. I think AI was useful here because I was able to learn how to solve problems I haven't seen before by seeing how AI solved the problems and it also helped me practice.
3. Quizzes, For the quizzes I did not use AI because I felt like it wouldn't benefit me. The quizzes were very similar to the WOD that we were working on previously so I felt confident that I would know how to complete all the requirements. There was also a time limit and I didn't trust AI enough to be able to get a solution that met all the requirements within the time limit.
4. Essays, For the essays I didn't use AI because I felt that AI could not answer the questions relating to this class. Most of the prompts were asking to write about your experiences and I could better talk about the experiences that I've had with some tools rather than AI.
5. Final Project, For the final project I used AI mainly on the concepts that I haven't seen before. For example, I was assigned to create the playwright tests for the pages and I haven't used playwright before so I used AI to help me learn and create the playwright tests.
6. Learning a concept, I have used AI to learn a concept, I think it is a useful tool because there are also many useful examples provided along with the information. I think the most useful aspect of using AI with learning is the questions that you can ask, if you are researching something you're not able to actively ask questions or consult on something that you're confused on.
7. Answering a question, I haven't answered much questions in discord. The most similar thing that I've done is talk with my group about the final project but I didn't use AI to answer questions that my group were asking or if we were just talking about what we were going to do.
8. Asking a smart questions, There weren't any questions in the smart questions channel. But most of the time I thought I had a smart question I would just research or consult with AI about the question I had and my question was answered.
9. Coding example, I have used AI to get a coding example, I didn't ask AI to give me a code example explicitly but when I had questions about a topic I would ask AI and the code examples that it would give were useful.
10. Explaining code, I have used AI to explain code, mostly this was for debugging code where AI would explain what code would fix the problem that I had. I think that this was useful to me because I learned new ways to solve a problem that wouldn't give me an error.
11. Writing code, I have used AI to write code, mainly when I was writing code the AI would autofill what I was going to type or even write a function, I also used AI to write code when I was unsure about how to go about solving a task like writing the playwright tests I used AI to help me write the tests.
12. Documenting code, I did not use AI to document code, most of the time where I added comments to code and explained what was done I felt that it would be best if it were written by me because I think that it is best to know what it does so you could better explain and document.
13. Quality assurance, I did use AI to make sure there are no errors, if there was an error code that I didn't see before or I was unsure how to resolve it I would ask AI if it could solve the solution. I think that it is useful because instead of having to research the error code and learn how to fix it I could ask AI how to fix the error while explaining it to me.
14. I don't think there are any other instances of using AI in ICS 314, the aspects that were already covered were the only times that I can think of where I used AI for this class.
